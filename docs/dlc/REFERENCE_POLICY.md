# Expansion Reference and Licensing Policy

Reference files are research-only and must not ship with the game.

For every collected reference, create a sidecar `metadata.md` containing:

- Source URL and access date.
- Creator/publisher.
- License or explicit usage permission.
- Allowed use: inspiration-only, internal, commercial, modification, attribution.
- What design question the reference answers.

Folder convention:

```text
references/dlc/mire/<subject>/metadata.md
references/dlc/veil/<subject>/metadata.md
```

Do not copy or trace reference-game cards, boards, symbols, illustrations, layouts, rules
prose, branded terms, or characters. Generated and commissioned art must use Hexbrewers'
gothic laboratory identity and the original briefs in `prompts/`.
